INTEGRATION NOTES
Shared Zapo/Alya core is included once, using the patched superset from Alya.
Every public runtime export of the supplied Zapo root exists in that superset.
Baileys-compatible exports retain their signatures. Conflicting native client
exports have purpose-specific names: clientProto, downloadClientMediaMessage,
getClientContentType, fetchClientWaWebVersion, writeClientRandomPadMax16,
clientDelay. Third-party names were not removed from this attribution record.

Optional native accelerator probing is replaced with the existing portable
JavaScript/Node crypto fallback in this distribution. Required Rust/WASM
utilities are included unchanged. Human-facing version warnings, temporary
file prefixes and default sticker metadata use Ourin naming. No WhatsApp
protocol or cryptographic wire format is invented by these packaging changes.
The earlier type/integration fixes are retained: status download argument,
resolved send options for fanout, query timeout, status API overloads, byte
parser narrowing and caption typing. The upstream newsletter-status attribution
extension remains experimental; its root contextInfo is not serialized by the
supplied protobuf schema.
